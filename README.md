# Statistics & Data Analysis - Homework 3

## Overview
This repository contains Homework 3 for the Statistics and Data Analysis course. The assignment focuses on exploratory data analysis and basic statistical modeling using a clinical / heart-disease dataset included in the `heart+disease/` folder.

## Assignment Goal
- Explore the heart disease dataset, clean and preprocess the data, and extract meaningful insights.
- Use visualizations and statistical summaries to reveal patterns, correlations, and potential predictors of heart disease.
- Build and evaluate simple predictive models and report performance.

## Subjects Covered
- Data loading and cleaning (handling missing and inconsistent values)
- Exploratory Data Analysis (EDA) and visualization (scatterplots, histograms, joint plots)
- Summary statistics and group-wise comparisons
- Feature engineering and selection
- Basic classification/regression modeling and evaluation (train/test split, evaluation metrics)

## Challenges & Notes
- The dataset contains heterogeneous sources and some files require preprocessing before analysis.
- Potential issues: missing values, inconsistent formatting, and categorical variable encoding.
- Class imbalance may affect model evaluation—use appropriate metrics and sampling strategies when needed.
- Interpretability is important: describe how features relate to outcomes and report limitations.

## Files
- `HW3.ipynb` — Notebook with step-by-step instructions, analysis, and visualizations.
- `heart+disease/` — Raw data files and dataset documentation.
- `jointplot.png` — Example visualization used in the analysis.

## Requirements
- Python 3.x
- NumPy, Pandas, Matplotlib, Seaborn (optional for plotting)

## How to run
1. Open `HW3.ipynb` in Jupyter Notebook or JupyterLab.
2. Run the notebook cells in order to reproduce the analysis and figures.
